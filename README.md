# СтальВектор — лендинг поставщика металлопроката

Одностраничный сайт для компании «СтальВектор»: продажа металлопроката со склада в Екатеринбурге. Задача лендинга — за один экран показать сильные стороны поставщика и собрать заявки на расчёт заказа.

## Решаемая задача

Клиент продаёт металлопрокат (трубы, листовой и сортовой прокат) со склада в Екатеринбурге. Типичные боли его покупателей: неуверенность в наличии и весе, долгое согласование цены, срыв сроков отгрузки. Лендинг снимает эти возражения и переводит посетителя в заявку:

- цифры склада и позиций сразу в первом экране и сниппете поиска;
- блок «Где обычно ломается поставка» — честный разбор болей с обещанием поведения;
- «Один поставщик на весь цикл» — услуги резки, доставки, комплектации;
- три кейса с конкретными сроками «заказ → отгрузка»;
- три формата работы с ценами;
- лид-форма «Заказать расчёт» — заявка, возврат с расчётом за 15 минут.

## Для кого сделан проект

Пользователь — снабженец или руководитель небольшой компании на Урале, которому нужен металлопрокат партией: ищет поставщика в поиске, заходит на сайт, проверяет сроки и оставляет заявку на расчёт. Владелец бизнеса получает входящие заявки без менеджера на обзвоне.

## Стек

- Чистый HTML + CSS, без фреймворков и сборщиков — один файл `index.html`, страница `privacy.html` с политикой конфиденциальности;
- адаптивная вёрстка (мобильные, планшеты, десктоп);
- шрифт Manrope (Google Fonts), иконки — инлайн SVG, без внешних библиотек;
- лид-форма — встроенная Яндекс Форма (`forms.yandex.ru`);
- сайт собран с помощью AI-ассистированной разработки (vibe coding): структура, тексты и код сгенерированы и доработаны через ИИ-агента.

## Как запустить

Статический сайт — сборка не нужна:

1. Склонировать репозиторий: `git clone https://github.com/Z01coder/steelvector-landing.git`
2. Открыть `index.html` в браузере — или запустить локальный сервер:
   ```
   python -m http.server 8080
   ```
   и открыть `http://localhost:8080`
